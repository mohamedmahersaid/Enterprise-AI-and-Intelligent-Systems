# Content provenance

This repository is an export of the **AI & Intelligent Systems** forest from Mohamed Maher Nada's Enterprise IT Academy taxonomy.

- Forest ID: `ai-intelligent-systems`
- Trees: 5
- Branches: 8 at export, 10 in this repository
- Leaves: 20 at export; `data/catalog.json` holds the current count
- Export date: 2026-08-11

Stable IDs are preserved in frontmatter and file names so corrections can be synchronized without relying on titles. The public repository is independently versioned after export.

Divergence from the export: the two trees that were exported with a single branch named after the tree have been split into two descriptively named branches each, so every tree has two branches; when the split was made, each branch held two leaves. Leaf IDs are unchanged, so synchronization by ID is unaffected; only the branch names and directory paths differ. Leaves have been added since then, so branches no longer hold two each; `data/catalog.json` and the curriculum map in `README.md` list the current set.
