# AI Platform Runbook

Operating the Claude Code environment for this repository.

## Health check

```bash
node .claude/bin/healthcheck.mjs            # add --offline to skip network probes
```

| Status | Meaning | Action |
| --- | --- | --- |
| PASS | Working as designed | None |
| WARN | Works, but differs from CI or lacks an optional tool | Fix when convenient |
| FAIL | Broken; gates or hooks will misbehave | Fix before working (exit code 1) |
| NOT CONFIGURED | Deliberately absent | None, unless the scope changes |

Areas covered: Claude Code, `CLAUDE.md` size, settings and permission rules,
hooks, skills/agents/rules frontmatter, project MCP, Node and `node_modules`,
`LEAF_PYTHON`, Git, tracked secret files, `actionlint`/`shellcheck`, Docker,
cloud CLIs, network to npm/PyPI/GitHub API.

## Common problems

| Symptom | Cause | Fix |
| --- | --- | --- |
| `Runtime: node_modules` FAIL | Fresh container or lockfile changed | `npm ci` (the startup hook does this in web sessions) |
| `LEAF_PYTHON` WARN | Local session, or the hook did not run | `python3.12 -m venv ~/.cache/leaf-python && ~/.cache/leaf-python/bin/pip install --require-hashes -r scripts/requirements.txt`, then `export LEAF_PYTHON=~/.cache/leaf-python/bin/python` |
| Edit refused: "is generated by `npm run regen`" | The derived-file guard | Edit `data/catalog.json` or the leaf, then `npm run regen` |
| Startup hook failed | Network to npm/PyPI blocked, or lockfile hash mismatch | Run `CLAUDE_CODE_REMOTE=true CLAUDE_PROJECT_DIR=$PWD .claude/hooks/session-start.sh` and read the error |
| `gh api .../logs` refused | Logs are on a blob host the proxy blocks | Use `mcp__github__get_job_logs` with `return_content: true` |
| GitHub Pages/variables API 403 | Proxy policy | Owner checks repository settings in the browser |
| `Tool: actionlint` WARN | Not installed in the container | `go install github.com/rhysd/actionlint/cmd/actionlint@v1.7.7`; make it permanent in the environment setup script |

## Making a session-local install permanent

Container installs vanish on restart. To keep a tool, add its install command to
the environment's **setup script** (cloud environment menu in the session title
bar, then Edit). Suggested lines:

```bash
go install github.com/rhysd/actionlint/cmd/actionlint@v1.7.7
uv tool install shellcheck-py==0.10.0.1
```

## Rollback

Every component is in Git. To roll back:

- One component: delete or revert its file (e.g. `.claude/hooks/guard-derived.mjs`
  and its entry in `.claude/settings.json`) in a PR.
- Everything: revert the PR that added `CLAUDE.md` and `.claude/`. No account,
  environment or external state was changed, so nothing else needs undoing.

## Changing the platform

1. Evidence first: a repeated step, a context flood or a recurring CI failure.
2. Smallest change: a rule line before a skill, a skill before an agent, an
   agent before an MCP server.
3. Validate: `npm test` (covers the hook, checker and frontmatter), the health
   check, and a real use of the component.
4. Record it in [CHANGELOG_AI_ENVIRONMENT.md](CHANGELOG_AI_ENVIRONMENT.md).
